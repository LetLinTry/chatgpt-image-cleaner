# ChatGPT Library 流式图片清理设计

## 目标

支持包含数万张图片的虚拟列表：无需预加载、预统计或一次性全选，持续以小批次删除当前可见图片，直到确认资料库中不再出现图片。

## 架构

扫描只用于确认当前页面存在可处理图片，不再声称得到总数。删除状态机维护累计删除量，而不是依赖当前 DOM 行数递减。每批选择当前可见图片，确认所选行被移除后等待列表补位；没有图片时自动滚动真实的内部滚动容器。只有连续多轮既无图片又无法继续滚动时才完成。

## 安全边界

- 仍仅在 `chatgpt.com` Library 页面运行。
- 每批只选择已由文件扩展名、图片预览或图片类型标签确认的图片行。
- 必须精确输入 `DELETE`。
- 页面级删除按钮或确认框不唯一时立即停止。
- 通过所选节点断开或身份变化确认批次成功，不以可见行数下降作为依据。
- 连续无进展、批次上限或用户取消时立即停止。
- 不调用未公开后端接口，不使用会删除文档/PDF的“全部清空”。

## 用户反馈

界面显示累计已删除数量和当前批次。扫描结果表述为“当前已发现可处理图片”，删除完成后显示实际累计删除数，不展示不可靠的预估总数。

## 测试

覆盖虚拟列表删除后等量补位、选中节点断开但可见数量不变、内部滚动容器定位与滚动、悬停挂载选择控件、空视口继续滚动、连续空轮完成、取消、无进展停止和非图片保护。
